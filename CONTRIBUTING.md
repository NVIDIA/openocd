# Reporting issues with NVidia's fork of OpenOCD
If you want to report a bug, feature request, or documentation issue
- File an [issue](https://github.com/NVIDIA/openocd/issues/new/choose)
describing what you encountered or what you want to see changed.
- Please run and paste the output of the [print_env.sh](https://github.com/NVIDIA/openocd/blob/main/print_env.sh) script while
reporting a bug to gather and report relevant environment details.
- The Tegra Debug team will evaluate the issues and triage them, scheduling
them for a release. If you believe the issue needs priority attention
comment on the issue to notify the team.
